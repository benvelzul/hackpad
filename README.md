# HACKPAD

This hackpad is a 4x4 that has a rotary encoder. 

ITs got 2 layers the first layer is like normal numpad while the second is for the mediaplayer and everything that needs shortcuts that a 65% keyborad doesnt have (my laptop doesnt have)
